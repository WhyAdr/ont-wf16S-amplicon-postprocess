## 2. Contracts v0.4.6 must enforce

### 2.1 Sample relative abundance

For sample `s` and taxon `t`:

```text
RelativeAbundance[s,t] = Count[s,t] / ClassifiedReads[s]
```

only when `ClassifiedReads[s] > 0`.

When `ClassifiedReads[s] == 0`:

- composition is undefined;
- stacked and heatmap sidecar abundance remains numeric zero and carries `ValidDenominator = FALSE`;
- the sample is excluded from taxon-selection means, group means, pseudocount derivation, and clustering distances;
- the residual `Other` value is zero, never one;
- a produced heatmap masks that column with a neutral NA color and an explicit denominator-status annotation.

Use the existing sidecar field name `RelativeAbundance`. Do not introduce `RawAbundance`; that name is absent from both the implemented schema and the parent plan.

### 2.2 Residual Other

For a valid sample:

```text
Other = max(0, 1 - sum(selected named taxa))
```

`Other` contains only unselected classified reads at the displayed rank. It does not contain all-read `Unclassified`, failed reads, or invalid-denominator state.

Sample stacked plots always include the residual when positive, so valid stacked sidecars must sum to one. Only heatmaps branch on `composition.heatmap_include_other`.

### 2.3 Group means

For group `g` and taxon `t`:

```text
GroupMean[g,t] = mean(RelativeAbundance[s,t])
                 over samples s in g with ValidDenominator == TRUE
```

Never substitute pooled counts:

```text
sum(Count[s,t]) / sum(ClassifiedReads[s])
```

If `SamplesUsed == 0`, the group mean is undefined, not zero. Retain the group in the TSV with `MeanRelativeAbundance = NA`, `SamplesUsed = 0`, and its exclusion count; render it as an explicitly invalid group rather than a zero-composition bar. A rank with no valid positive sample at all continues to emit the existing structured `*_skipped.tsv` files.

### 2.4 Taxon identity and labels

- `TaxonPath` is the aggregation and join key.
- `TaxonPath == "__OTHER__"` is reserved for the residual.
- Display labels are presentation only.
- The `TaxonPath -> DisplayTaxon` mapping must be identical under any input-row permutation.
- Labels must be globally unique, including collision with literal biological label `Other`.

### 2.5 Krona tree semantics

For every node:

```text
clade(node)  = direct(node) + sum(clade(child))
direct(node) >= 0
clade(node)  >= direct(node)
```

The XML must serialize:

- `magnitude = clade(node)`; and
- `magnitudeUnassigned = direct(node)`.

This matches pinned Krona 2.8.1 `ktImportText` semantics and preserves assignments terminating at an internal node.

### 2.6 Provenance path basis

Krona artifact paths in `krona_provenance.json` are POSIX-style paths relative to the completed run root, for example:

```text
07_Kreport/krona/S1.krona.tsv
07_Kreport/krona/S1.krona.html
```

They must remain valid after private-stage deletion and after moving the completed run directory as a unit. This restriction applies to artifact fields such as `tsv_path` and `html_path`; an external renderer's `resolved_executable` may remain an absolute tool-location record.
