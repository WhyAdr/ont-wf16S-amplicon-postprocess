# ONT wf-16S Amplicon Post-Processing Pipeline

Downstream analysis, taxonomic profiling, diversity quantification, and interactive Sankey report generation for Oxford Nanopore Technologies (ONT) full-length 16S rRNA amplicon sequencing data generated by EPI2ME `wf-16s`.

---

## Overview

This repository provides post-processing workflows for output generated by ONT's Nextflow-based [`wf-16s`](https://github.com/epi2me-labs/wf-16s) amplicon pipeline. It bridges primary bioinformatics outputs with publication-ready statistical visualizations and interactive taxonomic exploration.

### Key Capabilities

1. **Taxonomic & Diversity Profiling (`analyze_16s_improved.R`)**:
   - Comprehensive alpha diversity metrics (Observed Richness, Chao1, Shannon's $H$, Simpson's $D$, Inverse Simpson, Pielou's Evenness $J$, Fisher's $\alpha$, Berger-Parker dominance).
   - Rarefaction analysis with 100-iteration bootstrap subsampling to assess community sampling depth.
   - Per-read length diagnostics vs. classification success (violin/boxplot QC).
   - Relative abundance and composition analyses across all standard taxonomic ranks (Phylum, Family, Genus, Species) with high-contrast, colorblind-friendly palettes.

2. **NCBI Taxonomy Resolution (`fetch_ncbi_taxonomy.py`)**:
   - Resolves species-level assignments from Minimap2 alignments to official NCBI Taxonomy IDs using NCBI Entrez E-utilities (`efetch`).
   - Handles multi-rank taxonomic restructuring and lineage caching (`taxonomy_cache.json`) to minimize external API overhead.

3. **Kraken-format Conversion & Interactive Sankey Diagrams (`convert_to_kreport.R`)**:
   - Parses the 8-rank lineage abundance table into a standard 6-column Kraken report (`.kreport`) using depth-first search (DFS) tree traversal.
   - Pre-sorts clade abundances hierarchically so that the most abundant taxa anchor the top branches in downstream Sankey viewers.
   - Native compatibility with [Pavian](https://fbreitwieser.shinyapps.io/pavian/) for interactive HTML Sankey visualizations.

## Prerequisites & Dependencies

### R Environment
- R >= 4.0
- Packages: `dplyr`, `tidyr`, `stringr`, `ggplot2`, `scales`, `vegan`, `RColorBrewer`, `jsonlite`

```r
install.packages(c("dplyr", "tidyr", "stringr", "ggplot2", "scales", "vegan", "RColorBrewer", "jsonlite"))
```

### Python Environment
- Python >= 3.8

## Quickstart Workflow

### 1. Run Taxonomic & Diversity Profiling
```bash
Rscript analyze_16s_improved.R
```
*Outputs: 15 visualization figures in `figs/` and 7 summary CSV tables in `tables/`.*

### 2. Resolve Taxonomy to NCBI TaxIDs
```bash
python fetch_ncbi_taxonomy.py
```
*Outputs: `output_AAy/taxonomy_cache.json` mapping lineage paths to NCBI TaxIDs.*

### 3. Generate Kraken Report for Pavian
```bash
Rscript convert_to_kreport.R
```
*Outputs: `tables/<sample_name>.kreport`.*

### 4. Interactive Visualization
Upload the generated `.kreport` file to [Pavian](https://fbreitwieser.shinyapps.io/pavian/) or view the exported standalone diagram in `Pavian Sankey Ambar Ayunda.html`.
